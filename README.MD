# MÓDULO 1

En este módulo se eligió el tema del Proyecto Final, relacionado con el fenómeno del Superniño, mediante el proceso analítico jerárquico (AHP) de Saaty. Se compararon tres temas candidatos según cinco criterios. Las comparaciones se hicieron de a pares en la escala de 1 a 9, con la calculadora web AHP-OS, y se verificaron con una hoja de cálculo propia.

Se adjunta el Informe (**[´Informe_Módulo_1_Toma_de_Decisiones___TyHM_II.pdf´](´Informe_Módulo_1_Toma_de_Decisiones___TyHM_II.pdf´)**)
, así también como la planilla de excel (**[´AHPSeleccionTema-Modulo1.xlsx´](´AHPSeleccionTema-Modulo1.xlsx´)**)utilizada para verificar los resultados obtenidos.

El tema elegido fue la **planificación de la producción y el pronóstico de demanda en agroindustria bajo la variabilidad climática del Superniño**, con un 52,6 % del puntaje global. Su ventaja se explica sobre todo por la viabilidad y por la disponibilidad de datos públicos. Un análisis de sensibilidad con distintos escenarios de pesos confirmó que el resultado se mantiene.

Este trabajo se completa en el **Módulo 4**. Allí se toma la siguiente decisión del proyecto, en qué parque industrial de Mendoza se podría ubicar la planta agroindustrial, aplicando nuevamente el AHP. Esta vez se usan los datos calculados en el Módulo 3 (riesgo hídrico, empleo y ocupación de los parques) y todo el cálculo se resuelve con lenguaje SQL.
